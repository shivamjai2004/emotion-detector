# Emotion Detector - Final Project

This repository contains the Emotion Detector web application built using Python, Flask, Watson NLP / Embeddings emulation, and unit testing frameworks.

## Project Structure
- `EmotionDetection/`: Package folder containing `__init__.py` and `emotion_detection.py`.
- `test_emotion_detection.py`: Unit tests for the emotion detection functions.
- `server.py`: Flask web server handling API routing, rendering templates, and error handling.
